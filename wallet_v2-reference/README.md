# 接口文档概述

本文档旨在为开发者提供 **\[XQ6钱包系统]** Open API 的集成规范。

***

### 1. 核心交互机制

* **协议与格式**：基于 HTTPS 协议，采用 JSON 格式传输；业务参数统一存放在 `data` 节点内并进行 JSON 字符转义。
* **签名认证**：采用 **RSA (SHA256WithRSA)** 算法加密校验，通过 `signMsg` 字段保障传输安全。
* **状态判定**：`retCode = 000000` 仅代表通信成功；最终业务结果以 `data` 中的 `status` 为准（如 `100` 表示交易成功）。

***

### 2. 接口能力一览

* **账户管理** (`acct.*` / `wap.*`)：查询余额、获取进入钱包链接及提币地址。
* **充值服务** (`scan.deposits.*`)：商户扫码充值、主动查询与结果通知。
* **提现服务** (`withdraw.*`)：商户提币下单、状态查询与到账通知。

***

### 3. 开发接入规范

1. **防重机制**：保证 `merchOrderNo` 全局唯一，避免重复提交。
2. **异步通知**：终态结果通过回调地址通知，收包后须进行 RSA 验签。
3. **兜底对账**：发生超时或异常时，须主动调用 `*.query` 接口判定订单终态，禁止盲目重试。
